# Life Journey Simulator (Flutter)

A life simulation game created in Flutter, featuring:
- Dynamic aging mechanics & lifespan simulation
- Character stats: Health, Happiness, Smarts, Looks
- Education paths (High School, University)
- Career progression (Fast food worker up to Corporate CEO)
- Finance & salary management
- Real-time annual life events (diseases, romance, promotions, lotteries)
- Interactive web build and deployment

## Getting Started
To run locally:
```bash
flutter pub get
flutter run -d chrome
```
